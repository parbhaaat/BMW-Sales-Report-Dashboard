# 🚗 BMW Sales Report Dashboard

## 📌 Overview
This project is an interactive **BMW Sales Analysis Dashboard** built using **Power BI**, with data cleaning and preprocessing performed in **Python (Pandas)** and analytical queries solved using **SQL**.

The dashboard provides business insights into:
- 📈 Total Sales & Revenue
- ⚡ EV vs Hybrid Trends
- 💰 Revenue by BMW Models
- 🚘 Mileage vs Price Analysis
- ⚙️ Transmission-wise Sales
- 🌍 Regional Sales Performance
- 🏷️ Vehicle Classification Analysis

# 📌 Key Insights

✅ Hybrid and Electric vehicle sales show fluctuating yearly trends.

✅ BMW 7 Series and 3 Series generated the highest revenue.

✅ Manual and Automatic transmission sales are nearly equal.

✅ Asia recorded the highest regional sales.

✅ High classification vehicles account for more than 51% of total sales.
